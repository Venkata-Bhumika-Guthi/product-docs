# PR-14: Create Basic Auth with Token
## Summary
This pull request introduces a basic authentication system using token-based access. It hashes passwords with SHA-256, generates a UUID token upon successful login, and manages active sessions in memory. Additionally, comments have been added for testing and documentation purposes.

## Why this change exists
The change was made to implement a secure authentication mechanism that allows users to log in and access protected resources while ensuring that their passwords are stored securely.
