# PR-14: Create Basic Auth with Token
## Summary
This pull request introduces a basic authentication system using token-based access. It hashes passwords with SHA-256, generates a UUID token upon successful login, and manages active sessions in memory.

## Why this change exists
The change was made to implement a secure authentication mechanism that allows users to log in and access protected resources while ensuring that their passwords are stored securely.

## What changed (by area)
- **File Added**: `Basic Auth with Token`
  - Introduced functions for password hashing, token generation, user login, logout, and access control for protected routes.

## How to verify / test
1. Run the script in the `Basic Auth with Token` file.
2. Test the login function with valid and invalid credentials.
3. Verify that the token is generated and can be used to access the protected route.
4. Test the logout functionality to ensure tokens are invalidated correctly.

## Operational notes (rollout, migrations, feature flags)
**Not specified in PR materials.**

## Risks / edge cases
- If a user attempts to log in with an incorrect password or username, appropriate error messages are returned.
- The system currently stores active tokens in memory, which may lead to loss of session data if the application restarts.
